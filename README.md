## 🚀 Featured Project

### 🎮 LangForge — AI Game Translation Tool for Windows
> Capture your game screen. AI translates the text. Result overlays directly on the image.  
> Play any foreign-language game. Read everything. No interruptions.

- 🤖 5 AI engines: Gemini · Groq · Mistral · OpenAI · Claude
- 🌐 12 languages supported
- ⚡ Auto-capture · AI walkthrough analysis · Translation history
- 🟣 Public Beta available — free to download
